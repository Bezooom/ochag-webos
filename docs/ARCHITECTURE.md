# Архитектура

## Что чем управляет

```
включение ТВ
  └─ homebrew/init.d/90-launcher ──► launch tld.my.customlauncher (Hearth)
  └─ homebrew/init.d/85-home-watch ─► LG Home вышел на передний план ─► launch Hearth
  └─ homebrew/init.d/80-torrserver ─► setsid TorrServer --port 8090  (демон, живёт без GUI)
  └─ homebrew/init.d/50-lifesgood… ─► деблоат/антитрекинг (сторонний)

кнопка Home
  └─ LG Input Hook (org.webosbrew.inputhook) ─► keybinds.json: 773 ─► launch Hearth

OMP (com.spacesarmat.torrplayer)
  └─ HTTP ─► TorrServer :8090 (этот же ТВ) ─► p2p
```

## Почему демон, а не приложение TorrServer

Пакет `com.torrserver.app` не проходит проверку подписи на проверенной прошивке
(`-5: ipk verified failed`), а его GUI-обвязка — это Luna-сервис, который без установки
не регистрируется («Service does not exist»). Поэтому кит берёт из пакета **бинарь**
`bin/TorrServer`, кладёт его в `/media/developer/torrserver` и запускает как обычный демон.
Функциональность та же (веб-морда `:8090`, API `/torrents`), пропадает только телевизионный UI-скелет.

## Транспорты установки

| Условие | Транспорт | Причина |
|---|---|---|
| ipk ≤ 2 МиБ | HTTP с компьютера (`python3 -m http.server`) | установщик принимает только `http(s)` |
| ipk > 2 МиБ | HTTP **на самом ТВ** (`127.0.0.1:8081`, node) | установщик читает по ~1 КБ/с; локальный источник снимает сетевое плечо |

Оба пути передают `ipkHash` **голым** sha256 (без `sha256:`), иначе `Invalid file checksum`.

## Устойчивость

- Все хуки идемпотентны: повторный `install_hook` перезаписывает файл и запускает его.
- Хуки запускаются в фоне (`&`), чтобы не блокировать `startup.sh` — иначе страдает загрузка TV.
- `85-home-watch` опрашивает `getForegroundAppInfo` раз в 2 с: это дешёвый luna-запрос,
  но он же и единственная страховка, если Input Hook не поймал клавишу на конкретном пульте.
- Ни один шаг не перезагружает TV и не подменяет системные приложения — в отличие от метода
  «подменить `com.webos.app.home` и перезапустить SAM».

## Чего здесь нет

- Самописного лаунчера: Hearth быстрее и уже поддерживает обновления из HBC-репозитория.
- Своего плеера: OMP читает каталог TorrServer и отдаёт видео аппаратному декодеру LG.
- Автоматизации двух галочек в Hearth и адреса сервера в OMP: их API наружу не публикуют.
